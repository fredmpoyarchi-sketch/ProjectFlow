# ProjectFlow

Application Python de gestion de projets et de tâches développée avec la Programmation Orientée Objet (POO).

## Objectifs pédagogiques

- Apprendre la programmation orientée objet en Python
- Manipuler les classes et les objets
- Comprendre les attributs et les méthodes
- Utiliser l'encapsulation
- Comprendre l'héritage et la composition
- Gérer les exceptions
- Sauvegarder les données avec JSON
- Utiliser Git et GitHub avec Git Flow
